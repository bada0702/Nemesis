# search — 웹 검색 및 뉴스

## 설명
DuckDuckGo/Naver를 통한 웹 검색과 뉴스 조회를 지원합니다.

## 도구 목록
- `web_search(query)` — 웹 검색
- `search_news(query)` — 뉴스 검색 (기사 제목·내용·출처·링크 포함)
- `search_youtube(query)` — YouTube 검색

## 중요 규칙
- 뉴스 응답 시 반드시: 기사 제목 + 내용 요약 + 출처 + 링크 포함
- 검색은 최대 2~3회로 제한, 이후 수집된 정보로 즉시 답변 작성
- 동일 쿼리 반복 금지 (가드레일로 강제 종료됨)
